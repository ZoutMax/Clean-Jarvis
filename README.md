# Clean Jarvis

Privacy-hardened, group-safe edition of the JARVIS Home Assistant integration.

Targets **JARVIS 9.120.0**.

## Install via HACS

Add this repository as a custom repository in HACS (type: Integration), then install **JARVIS**.

## What is different

- Private by default: location, activity and camera data are admin-only until explicitly shared
- Group-safe: works correctly in multi-user households; non-admin users see only their own data
- Dynamic: follows your devices, rooms and users — nothing is hard-coded
